# Text Clustering Research

A research and engineering project for comparing practical text clustering approaches and building reusable clustering tools.

## Scope

- Organize text collections, with known or unknown cluster counts.
- Route new documents and reject unfamiliar categories.
- Work with hierarchical categories and evolving text streams.
- Compare quality, coverage, runtime and resource costs under explicit evaluation protocols.

## Public release status

This repository is being prepared for a reviewed public release. This initial page describes the project scope; source code and reproducible evaluation artifacts have not yet been published here.

Public releases will include only reviewed material based on public algorithms and appropriately licensed public resources. Private datasets, embeddings, operational logs and internal Git history are excluded. Dataset and paper links do not imply redistribution permission.
