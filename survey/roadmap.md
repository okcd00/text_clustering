# 覆盖缺口与推进顺序

[Survey 首页](README.md) · [方法地图](methods.md) · [数据协议](datasets.md)

这是实验建议，不是已经执行的结果。

| 优先级 | 产出 | 准入 / 停止条件 |
|---|---|---|
| P0 数据与证据基础 | BANKING/CLINC/MASSIVE manifest；新 pinned encoder 基线；独立 known-K/unknown-K 表 | 许可、文件 hash、split、无泄漏检查未通过就不跑；历史数字不改写 |
| P1 廉价且可解释的对照 | Top2Vec/BERTopic 完整管线与同矩阵控制；COSID split-only 路由压力测试 | 优先复用已有后端，不上逐样本 LLM；收益须跨 seed 与至少两个数据设置稳定 |
| P2 失败 case 定向改进 | 小拒识缓冲区的语义合并/命名，几何 vs LLM 配对 | 同时看 false merge/false accept、tokens/调用数/延迟；无明确离线增量则不扩大 |
| P3 层级及 topic 独立轨道 | SPARROW 父级放置；CTM/FASTopic 主题解释 | 先验证所需概念/监督是否存在；不把额外标签优势混入无监督榜 |
| 条件探索 | TabClustPFN、PEEL、完整 CIDA | 满足许可/权重/输入维度/监督/预算后才实验；当前只是参考，不是默认推荐 |

## 尚未填平的缺口

- **数据域**：现有证据偏英文单句意图；中文、长文、业务描述、多意图、极度长尾和真实事件流覆盖不足。先补数据，而非继续仅加算法名。
- **端到端新类**：拒识质量不等于聚合、命名、父级选择及审核后插入质量。需单独定义每步错误及累积影响。
- **演化**：增量 API 不保证跨窗口簇 ID 稳定、可追溯合并/拆分、内存上限或自然漂移适应。
- **论文覆盖**：已有广泛书目并非逐篇证据审计；ACL/EMNLP 近年重点之外，SIGIR/KDD/WWW/ICLR/NeurIPS 等需逐会核对正文与正式状态。不能据本版宣称“会议全覆盖”。
- **开放复现**：部分项目只有样例、未释权重/完整数据或许可不清；记录这些差异，而不把 GitHub 链接视作复现保证。
- **业务外推**：没有证据表明离线聚类提升必然改善实时意图或推荐指标；遵守先小规模离线 case/增量、后小流量下游验证的门槛。

## 后续每篇新增的最小卡片

正式来源与版本 → 任务与输入假设 → 已知/未知 K 与监督 → 数据与切分 → 核心结果及表号 → 代码/权重/许可/核对日期 → 成本 → 对现有基线的新增价值 → 能证伪它的最小实验。

仅新增 BibTeX 不算覆盖完成。每轮优先补“有书目但无证据卡”的核心条目，以及数据集可重建性；避免把重复预印本/会议版和共享软件 stars 重复计数。更新日期、来源检查与实验状态必须分开。

## 语义对照的下一道门槛

[semantic-pilot-v1 执行协议](../experiments/semantic-pilot-v1/README.md) 与 [实际结果](../results/semantic-pilot-v1/README.md) 已落地：独立 CPU 环境、固定 E5-small revision、双语 `query: ` 前缀、池化/归一化和 512 条/角色的无标签抽样，全部本地推理。原 preparation-only preflight 保留作历史记录，不再作为阻塞状态。

词面与语义使用同一批样本；oracle-K、固定未知 K、仅 validation 选参的未知-test-K 三种预算分开。小样本只检验流程，不作全量性能或稀有意图结论；向量优于词面的 oracle-K 结果不等于未知 K 的密度发现也改善。后续扩展不覆盖既有分数，而以明确版本和协议建立新结果。
