## 尚未填平的缺口

- **数据域**：现有证据偏英文单句意图；中文、长文、业务描述、多意图、极度长尾和真实事件流覆盖不足。先补数据，而非继续仅加算法名。
- **端到端新类**：拒识质量不等于聚合、命名、父级选择及审核后插入质量。需单独定义每步错误及累积影响。
- **演化**：增量 API 不保证跨窗口簇 ID 稳定、可追溯合并/拆分、内存上限或自然漂移适应。
- **论文覆盖**：已有广泛书目并非逐篇证据审计；ACL/EMNLP 近年重点之外，SIGIR/KDD/WWW/ICLR/NeurIPS 等需逐会核对正文与正式状态。不能据本版宣称“会议全覆盖”。
- **开放复现**：部分项目只有样例、未释权重/完整数据或许可不清；记录这些差异，而不把 GitHub 链接视作复现保证。
- **业务外推**：没有证据表明离线聚类提升必然改善实时意图或推荐指标；遵守先小规模离线 case/增量、后小流量下游验证的门槛。

## 后续每篇新增的最小卡片

正式来源与版本 → 任务与输入假设 → 已知/未知 K 与监督 → 数据与切分 → 核心结果及表号 → 代码/权重/许可/核对日期 → 成本 → 对现有基线的新增价值 → 能证伪它的最小实验。

仅新增 BibTeX 不算覆盖完成。每轮优先补“有书目但无证据卡”的核心条目，以及数据集可重建性；避免把重复预印本/会议版和共享软件 stars 重复计数。更新日期、来源检查与实验状态必须分开。

## 语义对照的下一道门槛

[semantic-pilot-v1 执行协议](../experiments/semantic-pilot-v1/README.md) 与 [实际结果](../results/semantic-pilot-v1/README.md) 已落地：独立 CPU 环境、固定 E5-small revision、双语 `query: ` 前缀、池化/归一化和 512 条/角色的无标签抽样，全部本地推理。原 preparation-only preflight 保留作历史记录，不再作为阻塞状态。

词面与语义使用同一批样本；oracle-K、固定未知 K、仅 validation 选参的未知-test-K 三种预算分开。小样本只检验流程，不作全量性能或稀有意图结论；向量优于词面的 oracle-K 结果不等于未知 K 的密度发现也改善。后续扩展不覆盖既有分数，而以明确版本和协议建立新结果。

## 下一个场景：先固定窗口，再比较更新策略

静态聚类与开放集路由已有同协议小规模结果。持续演化不能使用 BANKING77 或 MASSIVE 的原始行序冒充自然时间。UCI News Aggregator 的发布时间只支持**新闻标题的时间回放**，不是用户行为意图漂移。

[历史场景 18](../docs/scenarios.html?task=evolution_temporal_capacity&group=scenario-18) 已经做过一次按时间的 BIRCH 维护对照：原始标题视图中 26,842 条、7 个评分窗口。下表仅用于选择新协议的对照组，不进入本轮统一结果。

| 历史策略 | 窗口加权 ARI | 整个进程耗时 | 峰值 RSS |
|---|---:|---:|---:|
| 不限制叶微簇 | 0.462 | 295.8 秒 | 1,073 MiB |
| 叶微簇最多 2,048，触顶后停止更新 | 0.436 | 38.2 秒 | 545 MiB |
| 用最近 2,048 条定期重建 | 0.341 | 70.2 秒 | 605 MiB |

这是同一条过去看过的流上的描述性结果。原始压缩包哈希、切分边界和编码器版本无法从档案重建；去重标题视图与原始视图共用学习状态，也不是独立重复。[新协议的数据预检](../experiments/calendar-preflight-v1/README.md)已固定官方包、热身和七个 UTC 日窗，未运行编码或模型。后续做的是**标准化重跑**，不是宣称复现旧数值。

- 先用同一表示、日历边界、行顺序和热身状态，比较热身后冻结、不限叶微簇、触顶冻结、定期重建。每窗先保存预测再学习，不能用已有按条数分窗的流程冒充日历窗；测试标签只在评分时读取。低预算试验看触顶是否真的发生，未触顶就是未触顶，不看分数改预算。
- 同报窗口 ARI/NMI、覆盖和首见故事与延续故事的误差；ARI 是窗内指标。跨窗稳定性单独用同一份过去文本探针、无标签匹配后报告簇重合和未匹配比例；不能直接拼接各窗局部整数 ID。
- 状态量、时间和内存分开：叶微簇上限不等于字节上限；重建期间可能同时保有两棵树，结尾状态大小不能代替峰值。编码、预测、在线更新和重建的计时边界要写清楚，重建若已在更新时间内就不重复累计。
- 层级归属先固定金标准父子边和支持信息，再单独对照，不拿静态 ARI 当替代。
