范围与检索边界 #

- 核心：短文本/意图聚类、冻结语义表示上的聚类、LLM 辅助约束与解释、拒识后发现新类、类别树维护、文本流演化。

3. 开源项目怎么比较 #

带 stars 与许可的原始快照保留原日期，不以新文档日期冒充重新查询。

- BERTopic / Top2Vec：优先真实工程基线。仓库的 bertopic_pipeline 只是降维聚类核心，不等于完整 BERTopic。Top2Vec classic 将所有文档重新归到最近主题，不能把它的覆盖率直接与保留 noise 的 HDBSCAN 比；加一个“相同 HDBSCAN + 最近质心再分配”控制组。

- CTM / FASTopic：给定 K 的训练型 soft-topic 路线。若用 argmax 转硬标签，报告转换和覆盖规则；另报告主题质量。训练时间与冻结 encoder 聚类成本分开。

- TopMost：组织主题模型实验的工具箱，而非一种单独算法。先用作参考适配，不替换仓库既有协议。

- Contextual-Top2Vec：同 Top2Vec 仓库，不能重复计 stars；上下文版本为 beta 且 encoder 支持受限。

- 论文附属代码：区分 README 存在、完整代码/权重可获取、许可明确、成功运行、完整复现五个等级。缺失许可不是默认许可。

4. 当前本地证据对选型的约束 #

既有 WOS 单次配对里 top-1 NLI 把 hidden false accept 从 64.00% 提到 69.85%，known accuracy 仅 58.62%→58.96%；不能默认“加一次 LLM/NLI 就更准”。见完整口径。先找模型成本可控且能改善失败 case 的方案，再扩大离线 seed/数据范围；只有明确离线增量，才讨论下游小流量验证。

2. 暂不承诺开箱可复现的覆盖候选 #

- 中文新闻主题：C-MTEB、ThuNewsClusteringP2P.v2。它们补中文 topic，不替代中文 intent；原版嵌套任务行数不能当文档数，v2 不是同一协议。数据卡许可 unknown 时，不能套用框架许可证。先核对实际数据权利与 task revision，再纳入。

- 人工标注新闻流：Miranda et al., EMNLP 2018、官方代码。旧 FTP 数据入口当前可用性未验证；官方说明原始部分组件专有，公开的是复刻/预提取特征等。BSD-3 软件许可不等于新闻文本许可。列为待准入，不宣称可完整复现。

- COSID 分阶段意图：论文及官方实现。这是在 BANKING/CLINC 上构造的协议，不是新自然流数据集；随机、语义调度、旧类复现率/Zipf 不平衡分别记录。借 split 的低成本实验与完整 CIDA 复现分开。

- EB-NeRD 新闻曝光流（仅作协议参考）：官方字段给出 impression 时间、会话、记录为可见的文章 ID 与点击 ID；可见列表已打乱，不能恢复排位；公开说明中的 test 不含点击 ID，有标签的 train/dev 才适合上述回放。它来自筛选过的活跃读者，不是商品意图金标，也不能用点击缺失推断用户已无兴趣。仅在非商业推荐研究、符合原许可并走官方申请后考虑；许可还限制用途、存放与使用期限。本仓库未申请、下载或运行，也不将它纳入默认一键评估。

- 可证伪的问题：以预先固定的主题分组和观察窗，区分「无可见访问信号」「观察到访问但无同主题曝光」「有同主题曝光但未点击」。下一窗口仅在确有同主题曝光的机会中，比对时间衰减和基于机会的衰减对点击的预测，配平上次互动间隔、既往活跃度和曝光次数。比较是观察性的，不是去偏的策略因果估计。特征在当前截点冻结；排除未来阅读、滚动及含未来的文章统计，文章快照可能有后续编辑，不能验证时点版本时不把正文当作时点可见输入。默认文本聚类时间回放仍先选 UCI。

- KuaiSearch 中文电商搜索（目录候选）：论文 v4与组件/准入说明。独立 relevance 文件约 15.8 MB，Lite recall 约 258 MB，但 Lite 商品表约 2.79 GB、ranking 约 16.75 GB。相关性 0–3 是 query–item 配对监督，三级商品类目是代理分类体系，均非意图聚类金标；相对时间索引的单位和跨用户对齐尚未确认。HF 标注 MIT，论文 Appendix G 写 CC BY 4.0，许可冲突未解决。仅核对公开文献/文件元数据，未下载或运行；许可、来源、任务与泄漏审计完成前，不进入默认评估。

新实验必须记录以下字段；无法公开具体数据时，仅发布安全汇总与摘要，但不能声称完全可复现：

# Schema example, not a completed run
source: canonical dataset URL
revision: release or immutable commit
artifact_sha256: required before execution
license: dataset-specific license and notices
language: locale
text_field: exact field and preprocessing version
label_view: intent / domain / leaf_path / story
counts: raw, deduplicated, train, validation, test, known, hidden
split: official or derived; seed; held-out classes; grouping key
time: none / synthetic_stage / approximate_timestamp / verified_event_time

matrix: dimensions, preprocessing_fit_split, normalization, hash

budget: tuning trials, labeled support, LLM tokens/calls, hardware

1. 先锁分割再编码：按 document/utterance/story ID 去泄漏；若研究重复出现，明确它是目标而非意外泄漏。PCA/词表/归一化参数只在允许的训练/calibration 集拟合。

2. 双层对照：同矩阵后端比较回答“聚类器是否更好”；完整 native pipeline 比较回答“系统是否更好”。两个问题分栏，不能混因果。

3. 相同监督与调参预算：oracle K、已知类名、标注 pairs、gold hierarchy、LLM 外部知识均计入预算。跨语言 encoder/指令差异单列。

4. 同一噪声口径：同时报告接收和全量。Top2Vec 的全量再分配需配“相同密度聚类+最近质心”控制，不能把 assignment policy 当成表示突破。

5. 同一统计单位：种子配对；报告均值/SD、逐 seed 与样本数。共享向量的 CLINC domain/intent 不是独立训练；窗口不是独立数据集。仅单次结果不附伪造方差/显著性。

6. 同一成本边界：区分 encoder、fit、校准、预测、LLM 生成、维护、模型加载；报告峰值内存、吞吐/延迟及硬件。无法观测的账单写未知，不写零。

7. 留出盲测：旧 test 已被反复查看，只能做描述性配对；新改进须留新验证/测试或预登记配置。已有历史 checkpoint 不可获取时，建立新 pinned encoder 基线，不回填旧分数。

尚未填平的缺口 #

- 数据域：现有证据偏英文单句意图；中文、长文、业务描述、多意图、极度长尾和真实事件流覆盖不足。先补数据，而非继续仅加算法名。

- 端到端新类：拒识质量不等于聚合、命名、父级选择及审核后插入质量。需单独定义每步错误及累积影响。

- 演化：增量 API 不保证跨窗口簇 ID 稳定、可追溯合并/拆分、内存上限或自然漂移适应。

- 论文覆盖：已有广泛书目并非逐篇证据审计；ACL/EMNLP 近年重点之外，SIGIR/KDD/WWW/ICLR/NeurIPS 等需逐会核对正文与正式状态。不能据本版宣称“会议全覆盖”。

- 开放复现：部分项目只有样例、未释权重/完整数据或许可不清；记录这些差异，而不把 GitHub 链接视作复现保证。

- 业务外推：没有证据表明离线聚类提升必然改善实时意图或推荐指标；遵守先小规模离线 case/增量、后小流量下游验证的门槛。

序列化体积仅是存储代理，重建瞬间可能保有两棵树。算法进程 RSS 约 648–650 MiB，包含源数据解析和导入，不能据此证明算法 RAM 降幅。更新耗时含重建，不含编码、热身或预测；其他分项见完整 JSON。E5 本地编码 5,632 条标题约 83.54 秒，与聚类成本分开。两轮复跑证明确定性，不是统计置信区间。

日内 ARI 不追踪跨天簇身份；STORY 是银标新闻事件组，四大 CATEGORY 是另一任务。不与旧场景 18 的不同编码器、样本和计时口径比较。

ⓘ 新版内存测量和比较边界

每种策略每轮使用全新 worker，不读取源文本，也不加载编码器。输入 mmap 全量触页、相同数值 API 预热后设基线（约 163 MiB）；表中是 warmup／预测／更新阶段采样峰值减去此基线。文件与共享页、匿名 RSS、绝对 RSS、重建时双树共存及末态序列化分开记录。序列化仅含 BIRCH 估计器；rolling 另有至少 3 MiB 数值回放缓存和控制状态，已包含于 RSS，不是完整重启文件大小。这比 v1 更隔离，但增量仍含分配器保留、工作空间和采样开销，不是算法独占堆内存。

采样间隔名义为 5ms，并在阶段边界与双树共存点同步采样；调度可能延迟，短暂峰值可能漏掉，不能据此承诺不会 OOM。时间包含采样与重建，不含源准备、编码、热身和预测，不能跨版本比较速度。相同输入和导入条件下比较两轮结果；不跨任务排总榜。

跨日故事再次出现很少，不能当作新话题检测。 核对缓存哈希及已提交 v1 预检后，v1 是 2 / 597 个 STORY-日再次出现、3 / 3,584 条对应记录；v2 是 3 / 1,807 个 STORY-日、5 / 11,776 条记录，涉及 3 个不同 STORY。这里“再次出现”仅指在已选热身或此前已选日期见过；3 个均来自此前测试日期，热身交集为零。STORY-日逐日计数，不等于全期不同 STORY 数（v2 为 1,804）。首见标题评分保留相同原始历史：v2 为 3 / 1,800 个 STORY-日、4 / 11,685 条记录。详细日期及 v1 首见标题分母见审计说明。抽样历史中未见不等于语义新颖，跨日见过也不等于消失后重现；日内 ARI 不能代替校准误报的新话题检测或跨窗身份保留。

前一周已在 v1 看过，延长窗口是预登记续跑而非全新盲测；确定性复跑也不是统计置信区间。下一步可在独立时段复核，并单独研究重建时的内存回收策略，不根据这里的分数回调本轮参数。

可参考 Synthetic Fire Drill 的受控注入思路，分别观察被旧簇吸收、形成新簇及校准后的误报；只列为固定嵌入空间的压力测试参考，尚未在本库复现。背景新闻原文未公开，不能据此承诺原文重编码／端到端复跑，也不能把同一批行机械重放当作自然重现证据或汇入跨任务总榜。

ⓘ 层级实测的覆盖率、宏平均与比较边界

两方案共享同一 E5 表示、已知叶原型、叶预测和拒识掩码；父均值对归一化叶原型等权，不按支持行数加权，也不按查询重排候选。阈值规则在首次评分前锁定，只用验证集已知／隐藏标记最大化平衡正确率；无测试调参、无全局 oracle K。两次复跑预测及非资源字段完全一致。

全体隐藏查询的父类宏平均为 .615385 → .634615，联合宏平均 .471154 → .490385；每个测试隐藏父类恰有 8 条查询，因此这里宏平均与逐行比例相同，并非第二份独立证据。拒出子集父级正确是 49 / 89 → 51 / 89。已知叶接收后准确率 93 / 98（94.9%），但覆盖率只有 98 / 230，接收且叶正确仅 93 / 230；单／多子叶已知查询分母和验证集结果均在独立报告。

这是有监督已知拓扑上的父级归属，不是发现父类、创建新节点、自然流新意图检测或业务增益。与原 42 个静态／路由运行、历史层级场景及日历维护试验分开，不混用旧分数。预检保留原始记录，新结果另列 hierarchy-e5-v1。

MASSIVE zh-CN 的 scenario/intent 可作两层公开试验，但官方 intent 名称会泄露父类。层级输入只能给不透明节点编号、已知叶的父子边、支持样本及原始 utt；名称、带槽位文本、隐藏叶及其映射不参与决策。评价使用官方标注，不代表发现、命名或插入新节点。

平面路由原协议允许整个父类不在支持集，适合测拒识，不适合把其正确父类计作可达。层级试验应单列两种问题：

- 未见叶、父类可达：每个隐藏叶在训练支持集里有同父兄弟。验证、测试隐藏叶互斥；只用验证集设阈值。先比「最相近的已知叶映射到父类」与「直接比较等叶权重的父类原型」，保持输入与标签预算相同。并列全体隐藏叶的父类命中、成功拒叶且命中父类、已知叶覆盖与准确率，不能只看被接收子集。

- 父类不可达：父节点不在候选集中，单列拒绝或复核率和错接已知父类率；这里不报可达父类命中。若引入描述、外部 taxonomy、节点生成或 LLM，明确额外信息和独立协议。

层级切分的数据与接口预检已用固定 MASSIVE 数据验证：18 个父类都有实际支持，13 个测试隐藏叶（与验证隐藏叶互斥）、104 条隐藏测试行，没有跨角色的规范化文本重合。该历史预检本身只核验可达性、样本与方法输入，不含模型结果；上面的 hierarchy-e5-v1 独立完成首次 E5 父级归属评估，仍未测新节点质量。
