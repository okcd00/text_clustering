阅读路线 #

1. 方法地图与证据比较：先确定输入、输出、监督预算和失败模式，再选择论文。

2. 数据集选型与公平比较协议：先选数据和切分，再谈榜单；真实时间与合成流分开。

3. 复现优先级与覆盖缺口：哪些值得先做，哪些暂不应投入。

4. 原始参考库：逐篇来源与 BibTeX；开源生态快照：2026-11-13 的 stars、许可证和实现限制。

5. 新增独立可运行 lexical-v1 基线：两套完整 test、3 seeds、oracle-K/未知 K 和重复排除敏感性，明确不冒充语义模型比较。

6. 本仓库实测证据：批量协议、场景协议。下文的论文结果不是本仓库复现结果。

范围与检索边界 #

- 核心：短文本/意图聚类、冻结语义表示上的聚类、LLM 辅助约束与解释、拒识后发现新类、类别树维护、文本流演化。

- 邻接：主题模型、概念 taxonomy、表格聚类，用于借鉴或单独实验，不把它们的指标直接混入文本聚类榜。

- 文献层：以 2024–2026 近期工作为重点，保留早期基础方法；正式会议、Findings、演示、预印本和软件分别标注。题目或 arXiv 年份不等于录用证明。

- 软件层：优先有可检查代码、明确任务接口和实际采用度的项目。stars 是带日期的可见度快照，不是算法质量，不宣称“全网最高”。

- 来源顺序：正式论文集/论文正文 → 作者官方仓库及配置 → 数据发布页。二手列表只用于发现线索，不作为结果证据。

本轮审阅入口包括 ACL Anthology 的文本/意图聚类、topic modeling、taxonomy、continual intent discovery；ICLR/NeurIPS 原始论文入口；作者 GitHub 及仓库现有引用链。该过程是目的性筛选，没有宣称所有数据库已检索穷尽，也不虚构 PRISMA 检索数量。可复用关键词：text clustering, intent discovery, LLM clustering constraints, topic modeling, hierarchical taxonomy, stream clustering。

1. 按系统环节分组 #

静态、已知 K

最小基线
KMeans / MiniBatchKMeans
值得对照的路线
对比表示学习、LLM 约束、Bag-of-Texts、Summaries as Centroids
必须隔离的变量
K 来源、训练标签、表示/生成预算、测试时可见信息

静态、未知 K

最小基线
HDBSCAN / BERTopic 核心管线
值得对照的路线
Top2Vec、TopicMerge
必须隔离的变量
噪声、全覆盖再分配、初始微簇数、合并决策成本

主题解释

最小基线
c-TF-IDF 关键词
值得对照的路线
CTM、FASTopic、LLM-ITL
必须隔离的变量
soft topics ≠ hard clusters；coherence ≠ ARI；K 与词表需一致

新文本路由/拒识

最小基线
原型 / 多原型 / kNN
值得对照的路线
选择性语义验证、拒识缓冲区再聚类；NILC 为阅读对照
必须隔离的变量
known coverage 与 hidden false accept 同报；校准只能用 validation

类别树维护

最小基线
现有分层导航与 NodeProposal
值得对照的路线
SPARROW、PEEL、TaxoAgent
必须隔离的变量
概念词表/金标准边是额外信息；树与 DAG、归属与构树分开

持续演化

最小基线
frozen vs MiniBatch/BIRCH 更新
值得对照的路线
COSID 阶段协议、RAILS 增量路线
必须隔离的变量
阶段流≠真实时间；预测后学习；遗忘、簇 ID、内存增长须单测

邻接表格方法

最小基线
同矩阵几何基线
值得对照的路线
TabClustPFN
必须隔离的变量
文本适用性未证实；维度、K、批次归一化与非商业许可限制

2. 近期重点工作的证据卡 #

TopicMerge，EMNLP Findings 2026

可借鉴之处与原始证据
过分割微簇后做局部 LLM 合并；Table 1 Bills ARI .42、Wiki .71；Table 2 为 645/562 次 prompts
限制 / 下一步
基线调用数是估计下界，不是实测延迟节省；只有两个数据集；记录时作者代码不可访问。先几何合并 vs 语义合并配对

Dial-In LLM，EMNLP main 2025

可借鉴之处与原始证据
对话角色/上下文与迭代意图发现；Table 4 NMI 从 KMeans .7899 到 context-free .8208，再到 role merge .8826
限制 / 下一步
不把角色输入的收益全归为聚类器；完整训练集和微调权重可用性未建立。对话不是点击行为流

SPARROW，EMNLP main 2026

可借鉴之处与原始证据
完整概念集合上分块建树/融合；1K GPT-5 设置下 Product ancestor F1 .745 vs LLMscorer .453
限制 / 下一步
同设置 Edge F1 .579 vs .588，不能说全面提升。已有概念名、单父树，不是开放世界文本发现

PEEL，EMNLP main 2026

可借鉴之处与原始证据
冻结 embedding 上的轻量 containment probe；有助研究父子关系信号
限制 / 下一步
使用来源域金标准边与给定概念词表，不是无监督；98K 参数不代表整体系统零成本

LLM-ITL，ACL main 2025

可借鉴之处与原始证据
LLM 改善 topic words，置信加权 OT 训练
限制 / 下一步
保留为主题解释独立轨道；训练、生成、外部知识偏置均需核算

COSID / CIDA，EMNLP main 2026

可借鉴之处与原始证据
ClincCL α=.5，CIDA USR 6.22 vs VBCGCD 21.82，但 OSR .73 vs .47；明确新类漏检/旧类误拒的权衡
限制 / 下一步
默认配置 ESTIMATE_K=False 使用真实新类数。先借协议，不直接引入逐样本 LLM；完整定义见参考卡

各论文数据/表示/监督不一致，上表数字不能纵向排序。新旧类准确率、层级质量、聚类质量与业务推荐增量是不同终点。

3. 开源项目怎么比较 #

带 stars 与许可的原始快照保留原日期，不以新文档日期冒充重新查询。

- BERTopic / Top2Vec：优先真实工程基线。仓库的 bertopic_pipeline 只是降维聚类核心，不等于完整 BERTopic。Top2Vec classic 将所有文档重新归到最近主题，不能把它的覆盖率直接与保留 noise 的 HDBSCAN 比；加一个“相同 HDBSCAN + 最近质心再分配”控制组。

- CTM / FASTopic：给定 K 的训练型 soft-topic 路线。若用 argmax 转硬标签，报告转换和覆盖规则；另报告主题质量。训练时间与冻结 encoder 聚类成本分开。

- TopMost：组织主题模型实验的工具箱，而非一种单独算法。先用作参考适配，不替换仓库既有协议。

- Contextual-Top2Vec：同 Top2Vec 仓库，不能重复计 stars；上下文版本为 beta 且 encoder 支持受限。

- 论文附属代码：区分 README 存在、完整代码/权重可获取、许可明确、成功运行、完整复现五个等级。缺失许可不是默认许可。

4. 当前本地证据对选型的约束 #

既有 WOS 单次配对里 top-1 NLI 把 hidden false accept 从 64.00% 提到 69.85%，known accuracy 仅 58.62%→58.96%；不能默认“加一次 LLM/NLI 就更准”。见完整口径。先找模型成本可控且能改善失败 case 的方案，再扩大离线 seed/数据范围；只有明确离线增量，才讨论下游小流量验证。

2. 暂不承诺开箱可复现的覆盖候选 #

- 中文新闻主题：C-MTEB、ThuNewsClusteringP2P.v2。它们补中文 topic，不替代中文 intent；原版嵌套任务行数不能当文档数，v2 不是同一协议。数据卡许可 unknown 时，不能套用框架许可证。先核对实际数据权利与 task revision，再纳入。

- 人工标注新闻流：Miranda et al., EMNLP 2018、官方代码。旧 FTP 数据入口当前可用性未验证；官方说明原始部分组件专有，公开的是复刻/预提取特征等。BSD-3 软件许可不等于新闻文本许可。列为待准入，不宣称可完整复现。

- COSID 分阶段意图：论文及官方实现。这是在 BANKING/CLINC 上构造的协议，不是新自然流数据集；随机、语义调度、旧类复现率/Zipf 不平衡分别记录。借 split 的低成本实验与完整 CIDA 复现分开。

B-K：批量已知 K

输入/切分
同一文档集合，同一明确 K
核心指标
全量 ACC、ARI/NMI、时间/内存、多 seed
不能得出的结论
oracle K 优势不能冒充未知 K 能力

输入/切分

discovered K、coverage、全量噪声计错 ACC、接收子集 ARI/NMI
不能得出的结论

R：已有类路由/拒识

输入/切分

核心指标

CLINC 原生 OOS 与 held-out intent 不是同一未知分布

H：层级

输入/切分
固定树/父子标签，叶类隐藏协议
核心指标

不能得出的结论

S：合成阶段流

输入/切分
固定引入顺序、复现率、类不平衡；阶段内先预测后更新

old/new accuracy、OSR/USR、buffer、簇稳定性、成本

输入/切分

核心指标
每窗口质量、recurring/new story、时间/内存/延迟、维护成本
不能得出的结论
approximate timestamps 与 silver labels 不证明真实行为意图漂移

4. 每次比较必须冻结的 manifest #

新实验必须记录以下字段；无法公开具体数据时，仅发布安全汇总与摘要，但不能声称完全可复现：

# Schema example, not a completed run
source: canonical dataset URL
revision: release or immutable commit
artifact_sha256: required before execution
license: dataset-specific license and notices
language: locale
text_field: exact field and preprocessing version
label_view: intent / domain / leaf_path / story
counts: raw, deduplicated, train, validation, test, known, hidden
split: official or derived; seed; held-out classes; grouping key
time: none / synthetic_stage / approximate_timestamp / verified_event_time
encoder: model, immutable revision, instruction, pooling, truncation, dtype
matrix: dimensions, preprocessing_fit_split, normalization, hash
protocol: track, K source, noise/reassignment policy, update timing
budget: tuning trials, labeled support, LLM tokens/calls, hardware

1. 先锁分割再编码：按 document/utterance/story ID 去泄漏；若研究重复出现，明确它是目标而非意外泄漏。PCA/词表/归一化参数只在允许的训练/calibration 集拟合。

2. 双层对照：同矩阵后端比较回答“聚类器是否更好”；完整 native pipeline 比较回答“系统是否更好”。两个问题分栏，不能混因果。

3. 相同监督与调参预算：oracle K、已知类名、标注 pairs、gold hierarchy、LLM 外部知识均计入预算。跨语言 encoder/指令差异单列。

4. 同一噪声口径：同时报告接收和全量。Top2Vec 的全量再分配需配“相同密度聚类+最近质心”控制，不能把 assignment policy 当成表示突破。

5. 同一统计单位：种子配对；报告均值/SD、逐 seed 与样本数。共享向量的 CLINC domain/intent 不是独立训练；窗口不是独立数据集。仅单次结果不附伪造方差/显著性。

6. 同一成本边界：区分 encoder、fit、校准、预测、LLM 生成、维护、模型加载；报告峰值内存、吞吐/延迟及硬件。无法观测的账单写未知，不写零。

7. 留出盲测：旧 test 已被反复查看，只能做描述性配对；新改进须留新验证/测试或预登记配置。已有历史 checkpoint 不可获取时，建立新 pinned encoder 基线，不回填旧分数。

5. 建议第一轮（未执行） #

先用 BANKING77、CLINC150、MASSIVE zh-CN 建立英文细粒度/跨域/中文意图三格；每格相同 frozen encoder 下做 KMeans 与一种 unknown-K 基线，已知 K 和未知 K 独立。CLINC 同时设原生 OOS 与 held-out intents 两个拒识组。层级先解决 WOS 重建和标签一致性，再跑；流式先借 COSID split 测旧新类干扰，再进入 UCI 时间回放。

这轮目标是验证数据与协议可重复、找到稳定差异，不追求一次跑完所有论文，更不以英文分类标签上的 ARI 推断真实电商推荐增益。

6. 数据准备实证：先把比较的地基做实 #

可执行准备流程与完整审计口径。数据只下载到仓库外；没有模型调用，也没有向外部服务发送文本。旧榜单不变。

首个可运行基线：lexical-v1 #

本仓库新实测，独立于历史结果。 在 BANKING77 / MASSIVE zh-CN 全量官方 test 上，冻结字符 TF-IDF → 64 维 SVD → L2 表示，以 3 个随机种子比较 oracle-K KMeans、固定参数的未知 K HDBSCAN，以及全归一簇的 sanity control。无需模型、GPU 或外部 API；是词面基线，不是语义方法排名。

完整执行协议与逐 seed 结果。已完成独立的重复排除敏感性实验：BANKING77 从 3,080 到 3,071 条；MASSIVE zh-CN 从 2,974 到 2,696 条，均未丢失 test 中已有标签。删除所有 test 重复组及 train/dev 同文交集，不挑选“正确标签”的代表。每个新语料重新拟合表示，因此不能把分数变化解释为泄漏的因果效应。

尚未填平的缺口 #

- 数据域：现有证据偏英文单句意图；中文、长文、业务描述、多意图、极度长尾和真实事件流覆盖不足。先补数据，而非继续仅加算法名。

- 端到端新类：拒识质量不等于聚合、命名、父级选择及审核后插入质量。需单独定义每步错误及累积影响。

- 演化：增量 API 不保证跨窗口簇 ID 稳定、可追溯合并/拆分、内存上限或自然漂移适应。

- 论文覆盖：已有广泛书目并非逐篇证据审计；ACL/EMNLP 近年重点之外，SIGIR/KDD/WWW/ICLR/NeurIPS 等需逐会核对正文与正式状态。不能据本版宣称“会议全覆盖”。

- 开放复现：部分项目只有样例、未释权重/完整数据或许可不清；记录这些差异，而不把 GitHub 链接视作复现保证。

- 业务外推：没有证据表明离线聚类提升必然改善实时意图或推荐指标；遵守先小规模离线 case/增量、后小流量下游验证的门槛。
