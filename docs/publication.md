# 公开发布约定

公开仓库使用独立历史，不合并、镜像或推送内部仓分支。只有审核过的源码、公共引用、文档、汇总和逐种子统计可以入库。

禁止发布：凭据、内部域名和访问地址、用户/机器路径、内部数据、派生向量、逐文本预测、原始请求与响应、内部历史、LFS数据或论文PDF。下载数据应置于仓库之外。Git ignore不能保护已经跟踪的文件；发布前必须审查整个提交差异和新增文件。

运行 `python scripts/audit_public.py` 和测试后审核 `git diff --cached`。自动审核是补充，不替代人工数据授权与许可证审查。历史实验数字通过固定字段白名单导出，不复制完整配置或日志。

GitHub Pages仅部署 `docs/`；不部署源码工作目录、配置或本地缓存。
