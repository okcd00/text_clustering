Controlled fictitious-topic injection separates detection mechanisms. The paper reports absorption into existing clusters for its stream-clustering detections, not new-cluster creation, within its tested corpora/encoders/scenarios. This is bounded stress evidence, not a universal algorithm ranking.

The author README states real background article text is withheld for copyright reasons; metadata and precomputed embeddings are released. Fixed-embedding replay is therefore a different reproducibility claim from re-encoding the complete original text. Synthetic text availability does not fill that background-text gap.

For a future independent protocol, separate old-cluster absorption, new-cluster formation, latency and enrichment from calibrated false-alarm rates on background/null controls. These are distinct outcomes; detection count alone is insufficient. Repeating identical rows is not evidence of natural topic reappearance. Do not merge external reported scores into this repository's comparable benchmark grid.

This repository stores bibliographic metadata and primary-source links, not redistributed paper or corpus files.
