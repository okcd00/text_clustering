Citation key: `angelov2020top2vec`

- Authors: Angelov, Dimo.
- Venue/status: arXiv preprint; 2020.
- Original source: https://arxiv.org/abs/2008.09470

- Reviewed: 2026-11-13.

## Fit and limits

Joint document/word/topic embeddings and density-based topic discovery without supplied K. Useful interpretable baseline; preprocessing, encoder and density thresholds still affect results. Automatic K is not calibration-free open-set routing. Classic add/delete APIs do not by themselves prove stable-ID streaming adaptation.

See the [ecosystem and evaluation guide](../ecosystem_2026-11-13.md) for the dated popularity snapshot and proposed comparisons. This is a reference, not a reproduction, installed dependency or implemented backend. No upstream files/weights are redistributed.
