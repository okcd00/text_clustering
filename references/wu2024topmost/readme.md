## Fit and limits

Toolkit covering topic-model datasets, preprocessing, models, training and evaluation. Valuable for a controlled topic-model side benchmark, not an algorithm contender or ACL main research paper. Fix versions, data splits, vocabulary and encoder so convenience does not hide preprocessing differences.

See the [ecosystem and evaluation guide](../ecosystem_2026-11-13.md) for the dated popularity snapshot and proposed comparisons. This is a reference, not a reproduction, installed dependency or implemented backend. No upstream files/weights are redistributed.
