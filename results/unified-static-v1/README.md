# 第一轮同输入实测：静态聚类与开放集路由

[页面逐维度对照](https://dian.host/text_clustering/survey.html#compare) · [环境与算法配置](../../experiments/unified-static-v1/README.md) · [静态逐种子结果](results.json) · [路由结果与协议](../routing-v2/README.md)

2026-11-14。两套公开数据（BANKING77 与 MASSIVE zh-CN），三个种子。静态聚类每套固定 512 条测试文本、同一批归一化的 384D E5 向量，五种算法共 30 次。路由用另一套带支持集和互斥留出类的任务协议，共 12 次，不与静态结果混排。分别运行后，再用 `scripts/evaluate_survey.sh` 一次跑齐；两次所有非时间/资源指标一致。详见[重跑核验](reproducibility.json)。

## 已知 K：比较谁更好地划分给定数量的簇

| 数据 | KMeans ARI | MiniBatchKMeans ARI |
| --- | ---: | ---: |
| BANKING77 | 0.346 | 0.317 |
| MASSIVE 中文 | 0.313 | 0.318 |

KMeans 在 BANKING77 分数较高；MASSIVE 的均值接近，不据此宣布普遍胜者。两者都使用测试样本中实际出现的类别数，这是信息上限，不和未知 K 比谁更好。

## 未知 K：同时看全样本质量和覆盖率

| 数据 | HDBSCAN ARI / 覆盖 | BERTopic 核心 ARI / 覆盖 | EVoC ARI / 覆盖 |
| --- | ---: | ---: | ---: |
| BANKING77 | 0.010 / 36.7% | 0.147 / 85.8% | 0.117 / 77.9% |
| MASSIVE 中文 | 0.033 / 47.7% | 0.211 / 89.1% | 0.232 / 79.0% |

**BANKING77：**三个种子里，BERTopic 核心的全样本 ARI 和覆盖率都高于 EVoC；EVoC 的接收样本 ARI 则三个种子都更高。两者接收的是不同子集，后一个数字不能当作同一批文本上的比较。

**MASSIVE 中文：**EVoC 的全样本平均 ARI 较高，但优势不稳定。按种子 0/1/2 计算 EVoC 减 BERTopic 核心，差值为 +0.139、−0.066、−0.008；平均优势由种子 0 拉高，另外两个种子是 BERTopic 核心得分较高。EVoC 的平均覆盖率也更低。

本轮 BERTopic 只包含降维与聚类，不评价主题词或完整产品；固定参数的结果不是各算法调到最佳后的上限。全样本 ARI 把噪声作为一类；三个种子反映这批样本上的运行差异，不是统计置信区间。

## 路由：准确率的分母很重要

原型路由在两套数据上正确接收的已知样本占比都更高，隐藏类误接收也略低。MASSIVE 上最近邻的「已接收样本准确率」更高（81.5% vs. 79.5%），但已知类覆盖更低（27.7% vs. 40.1%）。因此先看系统愿意接收多少，再看接收后有多准。此结论仅适用于本次带标签支持集和固定留出类划分。

单线程耗时与 RSS 可在结果中查看；首次 JIT、缓存状态与进程导入影响口径，不能当稳态速度总榜。种子差异不等于抽样置信区间。层级、维护及真实时间流未纳入本轮，不用历史数据替代。
