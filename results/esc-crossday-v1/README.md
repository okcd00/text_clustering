# ESC 跨日故事延续：直接更新提高召回，也造成大规模误合并

**同一共享阈值 0.25 下，每日更新把跨日同主题召回从 26.8% 提到 89.0%，但准确链接占比从 59.7% 降到 4.1%，F1 从 0.370 降到 0.077。** 更新臂最大簇吸收 172/184 篇，解释了为什么不能只看召回。该设置中，不建议以直接更新替代冻结原型。两者都不是成熟的流式方案。

| 同一 ESC 测试集 | 主题对正确 / 误链接 / 漏链接 | 主题对 F1 | 已标注跨日事件链接捕获 | 簇 / 最大簇文档 |
|---|---:|---:|---:|---:|
| 冻结首文档原型，可新增簇 | 175 / 118 / 479 | 0.370 | 163 / 589 | 62 / 14 |
| 每天结束更新质心，可新增簇 | 582 / 13,784 / 72 | 0.077 | 524 / 589 | 9 / 172 |


**塌簇复核（仅用已发布汇总）：** 如果把同样的 184 篇测试文档全并为一簇，跨日同主题 F1 的上下界约为 0.07627–0.07776；每日更新的实测值为 0.07750，相差不到 0.0013。这说明本设置下的每日更新在该指标上接近「全部链接」的平凡规则，不能判定两者谁更高。没有重跑或重调阈值。

<details>
<summary>上下界怎么算</summary>
每日更新预测了 14,366 对跨日链接。172 篇的大簇外有 12 篇分在 8 簇，最多贡献 10 对链接，因此大簇内同日对数为 340–350。若大簇在任一天有至少 23 篇，即使其余文档尽量均匀地分到剩余最多 63 天，同日对也至少有 362 对。因此外部每篇至少能与大簇形成 150 个跨日对，全部跨日对至少 16,166 个；从全部 16,836 对中扣除大簇已知至少 340 个同日对，至多 16,496 个。全并规则召回全部 654 个跨日同主题正例，F1 为「两倍正例数 ÷（正例数 + 全部跨日对数）」。没有逐日篇数，无法由汇总算出精确 F1。
</details>

dev 61/65 篇、test 184/189 篇有可用于排序的 DCT；测试 16 个主题、64 个不同日期。两个分区用于回放的正文均无完全归一重复，跨分区精确归一重合为零；未审计近重复。两次运行汇总逐字节一致。结论只涉及这一个文档级预选样本和两项小基线，不外推到自然新闻流、语义编码器或实时意图。
